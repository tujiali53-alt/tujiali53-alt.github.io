基于 Unity DOTS 的 GPU 骨骼动画

项目背景

探索多个动画实体同时运行时，如何组织 CPU 侧的动画状态更新、动画数据传递和 GPU 渲染。

我的职责

独立开发 Unity Editor 动画烘焙工具、ECS 动画更新系统和渲染 Shader，实现多线程动画状态更新与材质属性传递。

技术方案

烘焙工具将骨骼动画数据写入二维纹理。运行时由 ECS 更新各实体的动画状态，Shader 根据状态采样对应的动画数据，再通过 GPU Instancing 批量绘制。
